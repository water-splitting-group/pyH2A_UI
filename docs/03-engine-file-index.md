Deep engine brief on pyH2A post-refactor (master @ a15e7bb): end-to-end execution model, declarative plugin I/O (input_dict/output_dict + input_resolver/output_inserter), the Quantity unit system, Time plugin, all 21 production plugins (100% resolver-based), the 7 Analysis modules (5 of which are BROKEN against the new DCF), the current markdown input format with a real excerpt, and a Pyodide/WASM feasibility assessment. Could not execute the engine (no scipy in any reachable interpreter; uv cache + /tmp writes blocked by sandbox) — all claims are from direct source reads, with runtime-behaviour inferences explicitly marked.

pyH2A(input_file, output_dir) -> Discounted_Cash_Flow(input_file) which (1) parses markdown into a 3-level dict {Table > Row > Column}, (2) merges referenced Defaults files, (3) resolves the Functional Unit, (4) sorts the Workflow table by Position and instantiates each plugin in order, each plugin being a class with _set_up (declares input_dict/output_dict specs) and _run (input_resolver_function -> compute -> output_inserter_function), all communicating ONLY through the shared dcf.inp dict using Quantity objects; the DCF itself is now just the last plugin (Discounted_Cash_Flow_Plugin, Position 900). Afterwards run_pyH2A scans top-level keys for '*Analysis' tables and executes those modules and their listed methods, returning matplotlib figures in .meta_modules.

- `pyH2A/src/pyH2A/run_pyH2A.py` — Top-level entry: pyH2A class. Parses input, runs Discounted_Cash_Flow, then meta_workflow() -> analysis modules + their Methods tables. Holds .inp, .base_case, .meta_modules.
- `pyH2A/src/pyH2A/Discounted_Cash_Flow.py` — Now a thin workflow executor (30 lines of logic after PR #176 stripped 527). Resolves functional unit, sorts Workflow by Position, executes plugins, check_processing(). NO LONGER has .h2_cost or .contributions.
- `pyH2A/src/pyH2A/Plugins/Discounted_Cash_Flow_Plugin.py` — The actual DCF math (804 lines), now a plugin at Position 900. NPV, MACRS, taxes, debt; emits Dependent Variables > Levelized cost > Value as Quantity(USD/<functional unit>).
- `pyH2A/src/pyH2A/Utilities/input_modification.py` — 1077 lines: markdown->dict parser, Defaults merging, path resolution ({A > B > C, unit}), process_input/process_cell/process_path, insert(), sum_table_quantity/sum_all_tables_quantity, identify_bottom_keys.
